## Featured Projects

### 1. PakNews Insight — News Analysis & Similarity

A news-analysis research project involving data collection, dataset preparation, and machine learning components.

- Implemented news scraping for Dawn and integrated SQLite for data storage.
- Worked on duplicate handling, dataset cleaning, and Pandas-based CSV preparation.
- Implemented text preprocessing and text similarity analysis.
- Developed image similarity and relevance-scoring components.

**Focus:** Python, SQLite, Pandas, data processing, text similarity, image similarity, and relevance scoring.

### 2. Agentic AI & Multi-Agent Workflows

Built agent-based solutions across hackathons, exploring AI-driven automation and coordinated workflows.

- Developed multi-agent systems using Fetch.ai and Google ADK 2.0.
- Explored applications in cybersecurity automation, DevOps workflows, and e-commerce recovery.
- Participated in hackathon projects associated with PI Innovate, CortexX, and AI Seekho.

**Focus:** Agent orchestration, automation, tool integration, and applied AI.

### 3. Deep Learning Framework From Scratch

Built a modular, object-oriented deep learning framework using NumPy to understand neural networks at a mathematical level.

- Implemented forward propagation and backward propagation.
- Worked with matrix operations, vectorization, and matrix calculus.
- Implemented gradient-descent-based optimization.
- Focused on understanding the underlying mathematics without relying on high-level deep learning frameworks.

**Focus:** Python, NumPy, linear algebra, calculus, neural networks, and optimization.

### 4. omegaUp — Open Source Contribution

Contributed to internal tooling and maintainability improvements in an existing codebase.

- Refactored legacy Redis-related logic into more strictly typed code.
- Used Mypy to improve type safety in background cron jobs and worker nodes.
- Helped address technical debt and improve code maintainability.

**Focus:** Python, Redis-related logic, static typing, Mypy, and open-source collaboration.

### 5. Zero-Trust-Web-Guardian

A collaborative security project focused on secure backend infrastructure and real-time threat mitigation.

**Focus:** Backend security, defensive engineering, and threat mitigation.
