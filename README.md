# Hi, I'm Muhammad Jami Ahad 👋

I'm an **AI & Backend Engineer** focused on building reliable software systems around **AI, automation, backend engineering, and machine learning**.

I work primarily with **Python**, designing modular and type-safe systems that connect models, APIs, databases, agents, and automation workflows.

My goal is simple:

> **Turn intelligent ideas into reliable software systems.**

### What I focus on

* 🧠 **Agentic AI & LLM Engineering** — agents, tool calling, memory, workflows, and multi-agent systems.
* ⚙️ **Backend Engineering** — APIs, service architecture, data pipelines, automation, and scalable system design.
* 🤖 **Machine Learning** — building and evaluating ML pipelines while understanding the mathematics underneath.
* 🐍 **Python Engineering** — modular architecture, type safety, clean interfaces, testing, and maintainability.
* 🧮 **From-Scratch Engineering** — implementing algorithms and mathematical foundations instead of relying entirely on abstractions.
* 🐳 **Systems & DevOps** — Docker, containerized applications, orchestration, and deployment fundamentals.
